# Marvel Universe Fan page

This webpage is a Marvel-themed site created using **Bootstrap** for Marvel fans. It features various sections of the Marvel Universe, including LEGO Marvel, Animated Series, MCU, Comics, and Multiverse. The page provides a visually immersive experience for Marvel enthusiasts, exploring different Marvel sub-universes through images, text, and interactive elements.

## Features

- **Responsive Design**: Fully responsive and mobile-friendly layout, built using the Bootstrap grid system.
- **Marvel Sections**: Organized content sections for different Marvel universes, including:
  - **MCU (Marvel Cinematic Universe)**: Showcases blockbuster MCU films and TV shows.
  - **Animated Marvel**: Displays iconic animated series such as *Spiderverse* and *X-Men: The Animated Series*.
  - **LEGO Marvel**: Features Lego sets and games from the Marvel universe.
  - **Marvel Comics**: A dedicated space for Marvel’s comic book legacy, highlighting major storylines.
  - **Multiverse**: An exploration of alternate realities and Marvel's "What If...?" scenarios.
- **Carousel**: An interactive carousel showcasing images with captions for different Marvel universes.
- **Interactive Elements**: Includes buttons that redirect users to external Marvel content, enhancing the user experience.

## Technologies Used

- **HTML5**: Provides structure for the content.
- **CSS3**: Custom styles for design elements and layout.
- **Bootstrap 5**: For responsive grid system and UI components.
- **JavaScript**: To add interactivity and functionality to elements such as the carousel.

## Structure of the Webpage

### Carousel
- **The main carousel**: Showcases images of the Marvel Universe with captions such as *Marvel Cinematic Universe*, *Comics*, and *Spiderverse*. Each carousel item has a different theme, with buttons linking to external Marvel resources.

### Marvel Sections
- **Multiverse & Alternate Realities**: A section dedicated to Marvel's multiverse with a focus on *What If...* scenarios.
- **Individual Stories & Character Arcs**: Features defining standalone stories and character arcs.
- **Animated Marvel**: Displays images and descriptions of iconic Marvel animated series like *Spiderverse*.
- **Lego Marvel**: Includes content related to Lego Marvel sets and games.
- **Marvel Cinematic Universe (MCU)**: Showcases MCU films and TV shows.
- **Marvel Comics**: A space dedicated to Marvel's rich comic book history.

### Footer
- **Contact Information**: Displays a contact email for users to reach out.
- **Creators Section**: Acknowledges the developers of the webpage.
- **Copyright Section**: Includes a copyright notice for the website.

## Usage

- **Home Page**: The landing page features a large carousel with themed slides of various Marvel universes.
- **Section Navigation**: Each section highlights a different facet of the Marvel universe with relevant images and brief descriptions.
- **Interactivity**: Buttons in each section link to additional resources such as the Marvel Comics website or search galleries.
